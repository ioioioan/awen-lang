# Continuity Example: ZeroReel Playback

This example shows a production contradiction moving through the continuity loop without allowing the build agent to redefine the product silently.

During implementation, the agent finds that one authoritative source suggests sending viewers to an external platform while another implies playback on the ZeroReel film page.

The example contains:

- `feedback/FEEDBACK_LOG.md` — the original observation and evidence;
- `decisions/DEC-001-film-playback.md` — the accepted resolution;
- `PROJECT_STATE.md` — the compact checkpoint for the next session;
- `project.awen` — the reconciled production contract.

In a real project, the affected product, UX and architecture sources would also be updated. They are referenced rather than reproduced here.
