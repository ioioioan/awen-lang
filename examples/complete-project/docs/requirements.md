# New Project — product requirements

Build a small personal task-list website. A visitor can create tasks, mark them complete, and remove them. The experience must work without an account or server. The site is a demonstration, not a production-grade multi-user task manager.

Acceptance scenarios:
1. Enter "Buy milk", submit, and see the new task.
2. Mark "Buy milk" complete, then unmark it.
3. Refresh and find the task and its completion state unchanged.
4. Remove the task and confirm it stays removed after refresh.
5. Submit an empty or whitespace-only value and confirm no task is added.
