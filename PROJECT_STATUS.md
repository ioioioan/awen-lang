# Project status and handoff

**Status:** Awen Lang v0.1 — public proposal, available for community use and contribution.

Awen is a human-readable assembly-sheet convention for passing settled decisions, exact sources, constraints and completion criteria to an AI execution tool. It is not a parser, runtime, memory system or agent orchestration framework.

## Start here

1. Read [README.md](README.md) for the purpose and smallest example.
2. Read [SPEC.md](SPEC.md) for language semantics.
3. Copy [TEMPLATE.awen](TEMPLATE.awen) to `project.awen` in a new project.
4. Follow [WORKFLOW.md](WORKFLOW.md) for a handoff.
5. Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing changes.

## What is established

1. The v0.1 vocabulary and repository conventions are documented.
2. Generic illustrative examples are provided.
3. No Awen-specific tooling is required to read the sheets.

## What is not established

1. Better outcomes than agent-native instructions or a clear Markdown brief.
2. Consistent interpretation across models and vendors.
3. Reliable cross-session continuity without a shared, current repository.
4. Production readiness for every domain or existing codebase.

## For future contributors

1. Test with a small reproducible task and publish the results, including failures.
2. Compare against an ordinary README or `AGENTS.md` baseline.
3. Fix contradictions and documentation defects before expanding the vocabulary.
4. Keep examples generic and self-contained.
5. Use numbered steps for sequential tasks and objective checks where possible.
6. Do not imply official endorsement or support from any AI vendor.
